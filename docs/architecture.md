# 아키텍처

## 현재 구현

`apps/web`은 npm workspace 안의 Astro 앱이다.
터미널 첫 화면과 About / Work / Contact 섹션을 포함한 홈, 404 페이지를 정적 HTML로 생성한다.
공통 레이아웃에서 탐색 메뉴, 한글 메타데이터와 반응형 스타일을 관리한다.
기존 초안의 글 목록·상세·프로젝트 페이지와 콘텐츠 컬렉션 및 실험 템플릿은 삭제했다.
Log는 보류 상태이며, 콘텐츠 컬렉션은 Log 구현 시 다시 구성한다.

현재 React island, 백엔드, 데이터베이스, 운영 환경의 Node.js 프로세스는 필요하지 않다.

## 계획한 운영 구조

```text
GitHub Actions → Astro 빌드 → Oracle VM 파일 시스템
브라우저 → HTTPS / Nginx → 정적 HTML, CSS, 자산
```

검색은 필요할 때 정적 검색 또는 클라이언트 측 검색으로 구현한다.
페이지네이션은 빌드 시 생성하거나 클라이언트에서 처리한다.
React는 필요성이 분명한 대화형 UI에만 사용한다.
서버에 지속적으로 보관할 상태가 필요해지면 저장소를 분리하지 않고
`apps/api` 서비스를 추가할 수 있다. Java + Spring Boot + Maven이 후보이다.
