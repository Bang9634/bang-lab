# 현재 상태

갱신일: 2026-09-08.

## 디자인 재작업

- 이전 홈 디자인을 폐기하고 화이트·블랙 중심의 미니멀한 첫 화면으로 교체함.
- 고정 헤더: 터미널 아이콘과 `Bang's Lab`, About / Work / Contact / Log.
- 브랜드는 홈 최상단, 섹션 메뉴는 부드러운 앵커 스크롤로 이동함. 헤더 높이 보정 없이 섹션 시작점을 뷰포트 최상단에 맞춤.
- 홈 → About → Work → Contact 순서로 뷰포트 높이 이상의 섹션을 구성함.
- About / Work / Contact 본문은 레이아웃 확인용 초기 문구이며 후속 작업에서 구체화함.
- Log는 비활성 메뉴로 보류함. 기존 `/posts/`, 글 상세, `/projects/` 페이지와 미사용 콘텐츠 컬렉션·실험 템플릿을 삭제함.
- 검은 배경에서 `welcomeText` 타이핑 후 확대·페이드하는 진입 효과를 구현함. 글자 크기를 `clamp(18px, 3.5vw, 46px)`로 축소함.
- 첫 로드 시 기존 해시를 제거하고 스크롤 복원을 끈 뒤 최상단으로 이동함. 로드 후 섹션 메뉴의 부드러운 이동은 유지함.
- 터미널 프롬프트 끝에 줄바꿈되지 않는 공백 한 칸을 추가함.
- 밝은 터미널에 `bang@localhost:~$`와 요청한 영어 문장의 타이핑·삭제 반복을 구현함.
- React와 새 의존성 없이 CSS와 작은 클라이언트 스크립트를 사용함.
- 동작 줄이기 설정에서는 진입 효과와 반복 애니메이션을 끄고 완성된 문장을 표시함.
- 새 구현의 타입 검사·빌드 통과. 가상 타이머로 타이핑·삭제·반복·탭 숨김과 복귀·동작 줄이기 처리를 검증함.
- 생성된 HTML의 섹션 앵커와 Log 비활성 상태를 확인함. 브라우저 시각 검증은 수행하지 않음.

## 구현된 내용

- Astro 7, MDX 통합과 strict TypeScript를 사용하는 npm workspace.
- 홈과 404 페이지. 홈 안에 About / Work / Contact 섹션을 배치함.
- 반응형 공통 레이아웃, 의미에 맞는 탐색 메뉴, 본문 바로가기와 포커스 스타일.
- Log와 콘텐츠 컬렉션은 추후 새로 구현할 예정이며 현재 공개 글은 없음.
- 한글 README, 아키텍처, 배포, 설계 결정, AI 컨텍스트와 저장소 작업 지침.
- 소스 코드와 작성 콘텐츠의 라이선스를 구분한 안내.
- 타입 검사, 빌드와 아티팩트 업로드를 수행하는 GitHub Actions CI 정의.

## 사이트 표시 정보

- 푸터 이메일은 `CONTACT_EMAIL`, 저작권 이름은 `PROFILE_NAME` 빌드 환경변수로 분리함.
- 이메일이 없으면 숨기고, 이름이 없으면 브랜드명을 표시함. 잘못된 이메일은 값 노출 없이 빌드 오류로 처리함.
- 기존 푸터 이름은 Git에서 제외된 로컬 `.env`로 이동함. 이메일은 미설정 상태임.
- `.env.example`에는 빈 항목만 제공함. CI는 main push에서만 secrets를 전달하며 원격 등록은 미수행임.
- 이 변경은 푸터에 적용함. 기존 문서나 라이선스의 정보 및 과거 Git 이력을 삭제하는 작업은 수행하지 않음.

## Welcome 중앙 정렬

- 사용자의 선호에 따라 너비가 늘어나는 기존 타이핑 방식과 `-0.05em` 자간을 복원함.
- 최종 너비는 문구 길이와 자간을 반영해 계산하여 완성된 문구를 중앙 정렬함.
- 타이핑 단계 수는 문구 길이에서 계산함. 타이핑 시간과 확대·페이드 설정은 유지함.

## 404 페이지

- 모노스페이스의 큰 `404`와 `NOT FOUND`, 짧은 오류 메시지를 중앙 배치함.
- `cd ~/` 명령어 형태의 홈 복귀 링크와 한글 안내를 제공함.
- 페이지 전용 스타일을 사용하고 이전 오류 화면의 미사용 공통 스타일을 제거함.
- 별도 클라이언트 스크립트나 의존성은 추가하지 않음.

## 첫 화면 문구 관리

- `index.astro` 상단의 `terminalText`를 화면 본문과 접근성 문구에 공통 사용함.
- 타이핑 스크립트는 초기 본문을 읽어 사용하므로 HTML 수정 후 이전 문장으로 덮어쓰던 문제를 해결함.
- 진입 문구는 같은 파일의 `welcomeText`로 관리함. 현재 사용자 설정은 `cd ~/`임.
- 진입 문구에 터미널과 같은 주기로 깜빡이는 흰 블록 커서를 추가함. 커서는 타이핑 너비를 따라 이동하며, 글자 중앙 정렬에 영향을 주지 않도록 절대 위치로 배치함.
- 기존 너비 기반 타이핑과 확대·페이드 시간은 유지하며, 커서도 문구와 함께 확대·페이드됨.

## 헤더 섹션 이동과 방문 기록

- 홈의 브랜드·로고·About·Work·Contact 링크만 기본 앵커 이동을 막고 `scrollIntoView`로 스크롤함.
- URL과 history를 수정하지 않으므로 헤더 섹션 이동은 뒤로가기 기록을 추가하지 않음.
- 기존 CSS의 부드러운 이동, 동작 줄이기 설정과 헤더 높이 보정 없는 정렬을 유지함.
- 수정키 클릭·새 탭·다른 페이지에서 홈으로 이동하는 링크는 기본 브라우저 동작을 유지함.
- 첫 로드 최상단 초기화와 본문의 Scroll to explore·본문 바로가기 링크는 기존 동작을 유지함.

## 최신 변경 검증

- 헤더 스크롤 변경 후 타입 검사·빌드 통과. 반복 클릭·키보드·수정키·새 탭·다른 페이지·없는 대상의 이벤트 처리를 검증함.
- 빌드 HTML에서 홈의 네 링크만 스크롤 전용으로 표시되고 404 링크는 기본 동작인 것을 확인함.
- 연결 가능한 브라우저가 없어 실제 뒤로가기 UI 검증은 수행하지 못함. 변경 전 쌓인 방문 기록은 삭제하지 않음.

- 환경변수 변경 후 타입 검사와 빌드 통과. 미설정 시 기본 표시, 설정 시 메일 링크·이름 표시, 잘못된 이메일의 빌드 실패를 확인함.
- 검증용 값으로 빌드한 뒤 로컬 설정으로 최종 빌드를 복원함. `.env` 제외와 `.env.example` 추적 가능 상태를 확인함.

- 타입 검사: 오류·경고·힌트 없음. 빌드: 홈과 404, 총 2개 페이지 생성.
- 초기 스크롤 재설정, 해시 제거, 쿼리와 history state 보존을 스크립트 검증으로 확인함.
- 생성 HTML의 프롬프트 공백과 기존 글·프로젝트 빌드 결과 삭제를 확인함.
- 실제 브라우저의 시각·스크롤 동작 검증은 수행하지 않음.

## 기존 로컬 검증 결과

다음은 초기 구현 당시의 결과이며, 문서 한글화 작업에서 다시 실행한 검증은 아니다.

- `npm run check`: 오류, 경고와 힌트 모두 없음.
- `npm run build`: 당시 콘텐츠를 기준으로 정적 페이지 4개 생성.
- 임시 공개 Markdown/MDX 글의 본문과 메타데이터 렌더링 확인.
  MDX 표현식도 정상 평가됐으며, 최종 빌드 전에 검증용 글을 삭제함.
- 초안 상세 페이지가 생성되지 않고, 최종 글 목록에 빈 상태가 표시됨.
- 샌드박스 밖에서 실행한 개발 서버의 `http://localhost:4321/` 응답이 HTTP 200이었음.
  당시 사용자 확인을 위해 서버를 켜두었으며, 현재 실행 여부는 별도 확인이 필요함.
- 브라우저 시각 검증과 원격 GitHub Actions 실행은 수행하지 않음.

## 최초 배포 점검

- 상세 결과는 `docs/deployment-review.md`를 참고한다.
- 뒤로가기 캐시 복귀 시 타이핑 재개와 빈 문구 처리를 보완했다.
- 타입 검사·빌드, 의존성 audit, 환경변수 처리 및 임시 Nginx의 실제 HTTP 응답 검증을 통과했다.
- 연결 가능한 브라우저가 없어 시각 검증은 수행하지 못했다.
