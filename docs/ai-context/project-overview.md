# 프로젝트 개요

bang-lab은 개발 과정을 기록하는 한글 기술 블로그이자 개인 포트폴리오이다.
README, 개발 문서와 AI 컨텍스트는 한글로 작성한다.
코드 식별자, 코드 주석과 커밋은 영어를 기본으로 한다.
Astro SSG와 Markdown/MDX를 사용하고, React island는 필요할 때만 추가한다.
계획한 호스팅은 Oracle VM + Nginx + Let's Encrypt + GitHub Actions이다.
Cloudflare는 필수가 아니며, 기본 선택으로 관리형 호스팅으로 대체하지 않는다.

전체 로드맵을 한 번에 구현할 대상으로 취급하지 않는다.
고급 기능을 추가하기 전에 동작하는 기준 구현과 재현 가능한 측정을 우선한다.
