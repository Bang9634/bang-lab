# 코딩 규칙

- 루트의 `AGENTS.md`를 따른다.
- 정적 UI에는 Astro 컴포넌트와 기본 HTML/CSS를 우선한다.
- strict TypeScript와 검증된 콘텐츠 메타데이터를 사용한다.
- 의미에 맞는 HTML, 눈에 보이는 키보드 포커스, 반응형 레이아웃과 한글 UI를 제공한다.
- 공통 페이지 구조와 스타일은 한곳에서 관리하되, 재사용되지 않는 추상화는 피한다.
- 배포 관련 파일은 `infra`, 개발 문서는 `docs`에 둔다.
- 현재 요구사항에 필요한 의존성만 추가한다.
- 정적/클라이언트 검색과 페이지네이션을 위해 백엔드를 추가하지 않는다.
- 실험 수치, 개인 성과나 완료하지 않은 작업을 만들어내지 않는다.
- 비밀정보, 빌드 결과와 로컬 의존성 디렉토리는 커밋하지 않는다.
- 기존 변경을 보존하고, 요청이 없으면 커밋하거나 배포하지 않는다.
- 관련 검증을 실행하고 `current-state.md`를 정확하게 유지한다.
